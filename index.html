Proyecto Inti

Cómo usar esta web

1. Selecciona una fecha en el calendario.

2. Selecciona una llamarada de la lista.

3. Revisa la información sobre la llamarada en la tarjeta.

4. Observa el modelo 3D del sol con la llamarada.(algunas visualizaciones pueden no estar disponibles)

Proyecto Inti usa datos de la API DONKI de la NASA
